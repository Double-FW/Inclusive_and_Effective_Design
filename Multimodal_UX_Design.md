# Multimodal UX Design --- GPT Knowledge Base

This knowledge base provides guidance for designers creating inclusive,
multimodal experiences across mobile, web, large screens, and voice
interfaces.

It is product‑agnostic and focuses on human experience rather than
technology or compliance.

------------------------------------------------------------------------

## 1. Foundations of Multimodal Inclusive Design

Multimodal design means experiences can be understood and controlled
using more than one sense and more than one interaction method.

Key principle: Meaning should survive across senses and interaction
methods.

Design considerations: - Provide alternatives for visual, audio, and
tactile perception. - Support multiple input methods such as touch,
keyboard, voice, and pointing devices. - Ensure equivalent usability and
enjoyment.

LLM Prompt Guidance: "Design this experience so that all key information
and controls work across visual, audio, and tactile modalities, and can
be used with multiple input methods including touch, keyboard, voice,
and assistive technologies."

------------------------------------------------------------------------

## 2. Human Context and Environment

People use products in varied environments with changing abilities.

Design considerations: - Noise, lighting, movement, fatigue, and
distraction affect usability. - Context changes cognitive load and
sensory reliance.

LLM Prompt Guidance: "Ensure the design adapts to different environments
such as noisy spaces, bright light, movement, or distraction, and
remains usable without reliance on a single sense."

------------------------------------------------------------------------

## 3. Multimodal Interaction Principles

Important information should not rely on a single modality.

Design considerations: - Reinforce actions with multiple cues. - Provide
confirmation through more than one sensory channel.

LLM Prompt Guidance: "Provide multimodal feedback using at least two
sensory channels for important actions, such as visual confirmation plus
sound or haptic feedback."

------------------------------------------------------------------------

## 4. Designing for Multiple Input Methods

Interfaces should support: - Touch - Keyboard or switches - Voice -
Pointing devices

Design considerations: - Avoid interaction methods that require
precision alone. - Provide alternatives for gestures.

LLM Prompt Guidance: "Ensure all interactions can be completed using
touch, keyboard-only navigation, voice commands, and pointer input
without loss of functionality."

------------------------------------------------------------------------

## 5. Designing for Multiple Output Modalities

Output includes: - Visual - Audio - Tactile

Design considerations: - Translate information across senses. - Provide
equivalents rather than duplicates.

LLM Prompt Guidance: "Provide equivalent ways to perceive all
information visually, audibly, and where possible through tactile
feedback."

------------------------------------------------------------------------

## 6. Content Structure and Hierarchy

Clear hierarchy improves accessibility across modalities.

Design considerations: - Prioritise information logically. - Separate
content from presentation.

LLM Prompt Guidance: "Structure the content so the hierarchy is clear
without relying on visual layout alone, and remains understandable when
read aloud by assistive technology."

------------------------------------------------------------------------

## 7. Responsive and Adaptive Thinking

# 17. Foundations of Multimodal Inclusive Design

Multimodal design means that experiences can be perceived and controlled
using more than one sense and more than one interaction method.

Inclusive multimodal design assumes: - Human ability varies - Context
changes ability - No single modality works for everyone

Core principle: Meaning must survive across modalities.

Design challenges: - Over‑reliance on visual interfaces - Input
assumptions (mouse or touch only) - Missing equivalents for sound or
motion - Fragmented experiences across platforms

Inclusive approaches: - Provide multiple sensory outputs - Provide
multiple input options - Reinforce meaning across channels - Ensure
parity of experience quality

Prompt guidance: "Generate solutions that ensure all information and
interactions are accessible through multiple sensory modalities and
multiple input methods, including assistive technology compatibility."

------------------------------------------------------------------------

# 18. Human Context and Environmental Variability

Human capability is dynamic.

Ability changes based on: - Lighting conditions - Noise levels -
Movement - Fatigue - Stress - Cognitive load - Physical constraints

Design challenges: - Designs that assume ideal conditions - Interfaces
that fail in real‑world environments - Sensory overload or deprivation

Inclusive approaches: - Provide adjustable feedback - Avoid reliance on
one channel - Support interruption and resumption - Reduce memory burden

Prompt guidance: "Ensure the experience remains usable in varied
environments including noisy, bright, mobile, or distracting contexts
without relying on a single sensory channel."

------------------------------------------------------------------------

# 19. Multimodal Interaction Principles

Important actions should be communicated through more than one sensory
pathway.

Key patterns: - Visual + audio confirmation - Audio + haptic feedback -
Visual + motion cues - Redundant signalling for critical states

Design challenges: - Silent failures - Invisible system states -
Ambiguous feedback

Inclusive approaches: - Layer feedback across senses - Provide state
awareness continuously - Avoid relying on colour alone

Prompt guidance: "Provide multimodal feedback for all important system
states, combining at least two sensory channels to reinforce meaning and
confidence."

# 20. Input Flexibility and Control Diversity

Users should be able to control interfaces using:

-   Touch
-   Keyboard or switches
-   Voice
-   Pointing devices
-   Assistive technologies

Design challenges: - Precision requirements - Gesture-only
interactions - Keyboard traps - Voice-only assumptions

Inclusive approaches: - Provide alternative controls - Ensure logical
navigation order - Support interruption and correction - Avoid time
pressure where possible

Prompt guidance: "Ensure every interaction can be completed using touch,
keyboard-only navigation, voice commands, and pointer input without loss
of functionality."

# 21. Output Modalities and Sensory Translation

Information should exist across:

-   Visual output
-   Audio output
-   Tactile output (where available)

Design challenges: - Visual-only information - Audio-only alerts -
Motion without alternatives

Inclusive approaches: - Translate meaning across senses - Provide text
equivalents for media - Provide audio equivalents for visuals - Use
tactile feedback for confirmation

Prompt guidance: "Provide equivalent perceptual access to all
information across visual, audio, and tactile modalities so users are
not dependent on a single sense."

# 22. Content Structure and Hierarchy

Clear structure supports multimodal accessibility.

Design challenges: - Presentation-first thinking - Complex layouts
masking hierarchy - Information overload

Inclusive approaches: - Define content priority first - Maintain logical
reading order - Use clear grouping - Separate meaning from layout

Prompt guidance: "Structure content so it remains understandable without
visual formatting and can be interpreted correctly by assistive
technologies."

# 23. Responsive and Adaptive Thinking

Design for variability rather than fixed devices.

Feature dependency

Inclusive approaches: - Start with a simple core - Enhance
progressively - Maintain consistency across contexts - Allow flexible
interaction paths

Prompt guidance: "Create a flexible experience that works across screen
sizes, input methods, and capabilities, starting with a simple core
interaction and enhancing where possible."

# 24. Touch and Gesture Interaction

Touch interaction should be forgiving and predictable.

Design challenges: - Small targets - Gesture dependency - Hover
reliance - Accidental activation

Inclusive approaches: - Provide large activation areas - Allow spacing
between targets - Support simple taps as alternatives - Use natural
gestures where appropriate

Prompt guidance: "Design touch interactions that are forgiving, have
large activation areas, avoid reliance on hover, and provide simple
alternatives to complex gestures."

supportive tone

Prompt guidance: "Design conversational interactions that use simple
language, confirm actions clearly, allow recovery from
misunderstandings, and minimise memory load."

# 32. Multimodal Design Process Framework

Recommended steps:

1.  Identify meaning
2.  Map sensory equivalents
3.  Map input options
4.  Evaluate context variability
5.  Design feedback loops
6.  Test across modalities
7.  Refine for parity

Prompt guidance: "Follow a multimodal design process that identifies
meaning first, then creates equivalent sensory and interaction pathways
before refining for usability and enjoyment."

  --------------------------------------------------------

Designers should assume variability is normal.

Design challenges: - Designing for an imagined "average user" -

Inclusive approaches: - Provide multiple sensory pathways - Provide
multiple interaction methods - Reduce reliance on memory - Provide
adjustable demands

LLM prompt guidance: "Generate design solutions that assume users have
varied sensory, motor, and cognitive abilities and ensure equivalent
usability regardless of these differences."

## Knowledge Base for Designers and AI-Assisted Workflows

------------------------------------------------------------------------

# 1. Foundations: Designing for Human Variability

Design accessibility is fundamentally about recognising that people
perceive, understand, and interact with interfaces in different ways.
Human capability varies across vision, hearing, cognition, language
processing, motor control, attention, and sensory sensitivity, and these
differences are influenced by context such as fatigue, environment, or
stress. When accessibility is considered early, experiences become
easier for everyone, not just disabled users, because clarity,
predictability, and flexibility reduce friction universally. Designing
inclusively also improves trust, satisfaction, and brand perception by
demonstrating respect for user autonomy and dignity.

## Design Approach and Methodology

Designers should treat accessibility as a creative constraint rather
than a compliance requirement. Begin by mapping interaction journeys
through multiple sensory channels --- visual, auditory, tactile, and
cognitive --- and identify where a user might encounter barriers if one
channel is unavailable. Apply iterative prototyping with diverse
personas representing different abilities and contexts, and validate
designs against real-world variability rather than idealised users.
Consider accessibility decisions as part of core design critique, not as
a later audit step.

## Prompting an LLM for Accessible Outcomes

When using an AI model to generate design ideas:

-   Explicitly state that outputs must be perceivable through multiple
    senses.
-   Request descriptions that work for assistive technology users.
-   Ask for alternatives for users who cannot see, hear, or perform
    precise gestures.
-   Require structured outputs that separate visual presentation from
    meaning.

------------------------------------------------------------------------

# 2. Predictability and Consistency

Consistency enables users to build mental models. When layouts,
controls, terminology, and behaviours change unpredictably, cognitive
effort increases and errors become more likely. This particularly
affects people with cognitive differences, memory limitations, or
attention challenges, but also benefits all users by reducing learning
time and uncertainty. Predictable interfaces allow users to transfer
knowledge from one context to another, improving efficiency and
confidence.

## Design Approach and Methodology

Design systems should define consistent patterns for navigation,
interaction states, feedback, and terminology. Maintain alignment
between visual appearance and functional behaviour so that controls look
like what they do. Ensure interaction patterns follow established
conventions unless there is a strong reason to deviate, and if deviation
occurs, provide clear cues and guidance. Evaluate consistency not only
within a single screen but across journeys and product ecosystems.

## Prompting an LLM for Accessible Outcomes

When generating designs with AI:

-   Specify that patterns must remain consistent across screens and
    states.
-   Request alignment between visual affordance and function.
-   Ask for predictable navigation logic and terminology reuse.
-   Require explanations of how users learn and recognise patterns.

------------------------------------------------------------------------

# 3. Media Control and Autoplay

Unexpected sound or motion can disrupt users who rely on assistive
technologies, are sensitive to sensory input, or need cognitive focus.
Automatically playing media may interfere with assistive output, startle
users, or create confusion about where sound originates. Giving users
control over when media begins respects autonomy and prevents cognitive
overload. Media experiences should never remove a user's ability to
control their environment.

## Design Approach and Methodology

Design media experiences around user initiation rather than system
initiation. Provide clear controls for play, pause, mute, and navigation
that are easy to locate and operate. Consider sensory load carefully ---
motion, sound, and visual complexity should be adjustable or optional.
Provide meaningful feedback about media state so users understand what
is happening without ambiguity.

## Prompting an LLM for Accessible Outcomes

Ask AI tools to:

-   Avoid automatic playback unless user consent is included.
-   Provide clear, labelled controls for media interaction.
-   Include captions, transcripts, and visual alternatives.
-   Describe how controls remain accessible across input methods.

------------------------------------------------------------------------

# 4. Video and Complex Interactive Controls

Complex media controls involve multiple states, timelines, and feedback
mechanisms. If poorly designed, they can become confusing, inaccessible
to keyboard users, or difficult for assistive technologies to interpret.
Controls must communicate both current state and possible actions
clearly so users maintain orientation. Effective design reduces
cognitive effort while enabling flexible interaction.

## Design Approach and Methodology

Use familiar metaphors and patterns for controls, ensuring states are
visually and semantically distinguishable. Provide feedback that
communicates progress and status through more than colour alone. Ensure
that interaction sequences can be performed step-by-step rather than
requiring continuous gestures or precise timing. Consider progressive
disclosure so complexity appears only when needed.

## Prompting an LLM for Accessible Outcomes

Specify:

-   Controls must expose their state clearly.
-   Interaction must work without precise gestures.
-   Information about progress must be available textually.
-   The experience must remain usable without vision.

------------------------------------------------------------------------

# 5. Iconography and Visual Symbols

Icons can support comprehension but cannot replace text because meaning
depends heavily on cultural familiarity and prior knowledge. Without
text, icons may become ambiguous, especially for users with cognitive
differences or those using assistive technologies. Icons should
reinforce meaning, not carry it alone. Accessible icon design
prioritises clarity, scalability, and interpretability.

## Design Approach and Methodology

Pair icons with text labels whenever possible, ensuring users can
understand content without visual interpretation alone. Use established
symbols rather than inventing new ones to reduce learning burden. Design
icons that scale clearly and maintain contrast across contexts. Treat
icons as supportive cues within a broader communication system rather
than primary communication tools.

## Prompting an LLM for Accessible Outcomes

Request that AI:

-   Always include text alternatives alongside icons.
-   Explain icon meaning explicitly.
-   Avoid relying solely on symbolism for communication.
-   Consider recognition across cultures and abilities.

------------------------------------------------------------------------

# 6. Input Adaptability and Interaction Flexibility

People interact using many methods: touch, keyboard, voice, switches, or
assistive devices. Rigid interaction models exclude users who cannot
perform precise gestures or complex motor actions. Adaptable input
ensures users can choose the method that works best for them.
Flexibility also benefits situational contexts such as one-handed use or
environmental constraints.

## Design Approach and Methodology

Provide multiple ways to perform the same action, such as buttons
alongside gestures. Allow adjustment of interaction speed, sensitivity,
and complexity where appropriate. Design controls that minimise
precision requirements and allow recovery from errors easily. Consider
progressive modes, from simple to advanced, to accommodate different
ability levels.

## Prompting an LLM for Accessible Outcomes

Ask for:

-   Multiple input methods for every action.
-   Adjustable interaction difficulty.
-   Alternatives to gestures requiring precision.
-   Descriptions of how users with motor differences complete tasks.

------------------------------------------------------------------------

# 7. Input Format and Form Design

Forms can create barriers when expectations are unclear or formats are
rigid. Users may struggle to interpret requirements, remember
instructions, or correct errors. Clear labelling and guidance support
independence and reduce frustration. Accessible forms benefit everyone
by improving completion rates and reducing mistakes.

## Design Approach and Methodology

Use explicit labels that describe what information is required and why.
Provide examples and contextual hints without replacing the primary
label. Align input expectations with user mental models, avoiding
unnecessary complexity. Design error handling that is informative, calm,
and recoverable without blame.

## Prompting an LLM for Accessible Outcomes

Specify:

-   Every input requires a clear descriptive label.
-   Instructions must remain visible.
-   Error feedback must be understandable and actionable.
-   Interaction must work with assistive technologies.

------------------------------------------------------------------------

# 8. Keyboard Access and Focus Management

Many users rely on keyboards or equivalent devices rather than touch or
mouse input. If focus order is illogical or invisible, navigation
becomes disorienting. Accessible focus behaviour ensures users know
where they are and how to proceed. Reliable navigation supports
independence and efficiency.

## Design Approach and Methodology

Design logical navigation sequences that follow reading order and visual
structure. Provide visible focus indicators that clearly highlight the
current interactive element. Ensure that all interactive components can
be reached and operated without pointer input. Avoid unexpected focus
movement that disrupts orientation.

## Prompting an LLM for Accessible Outcomes

Request:

-   Clear navigation order descriptions.
-   Visible focus cues.
-   Keyboard-operable interactions.
-   Consistent behaviour when new content appears.

------------------------------------------------------------------------

# 9. Avoiding Interaction Traps

Interaction traps occur when users cannot move away from a component
using their chosen input method. This can create anxiety, confusion, and
loss of control. Ensuring escape routes preserves user autonomy and
prevents abandonment. Users must always retain control over their
navigation path.

## Design Approach and Methodology

Design every interactive element with an exit pathway that is obvious
and accessible. Modal or layered content should include clear mechanisms
for dismissal. Avoid behaviours that override user navigation patterns
unexpectedly. Consider user recovery as a core design requirement rather
than an edge case.

## Prompting an LLM for Accessible Outcomes

Ask AI to:

-   Ensure users can exit any interaction state easily.
-   Provide visible and descriptive escape controls.
-   Maintain navigation continuity.
-   Describe how users regain context after closing content.

------------------------------------------------------------------------

# 10. Touch Targets and Physical Interaction

Small or crowded touch targets increase error rates and frustration,
particularly for users with motor differences or low vision. Larger
targets improve usability for everyone, including people using devices
in motion or with limited attention. Adequate spacing reduces accidental
activation and cognitive load. Physical interaction design should
respect human variability in precision and reach.

## Design Approach and Methodology

Design interactive elements with generous size and spacing, prioritising
comfort over density. Group related items into unified targets when
appropriate to increase usable area. Consider reach zones, hand posture,
and device context when placing controls. Validate designs through
physical testing rather than visual inspection alone.

## Prompting an LLM for Accessible Outcomes

Specify:

-   Controls must be large and well spaced.
-   Interaction must tolerate imprecision.
-   Layout must consider reach and ergonomics.
-   Users with motor differences must complete tasks independently.

------------------------------------------------------------------------

# 11. Multimodal Communication

Accessible design communicates meaning through multiple channels
simultaneously --- visual, textual, auditory, and structural. Relying on
a single sensory channel excludes users who cannot access it. Multimodal
communication increases comprehension, retention, and usability across
diverse contexts. Designing redundantly across channels improves
resilience and clarity.

## Design Approach and Methodology

Ensure that information conveyed visually is also available textually
and structurally. Provide alternatives for audio content and
descriptions for visual content. Consider how meaning persists when one
sensory channel is removed entirely. Treat multimodal communication as a
baseline requirement rather than an enhancement.

## Prompting an LLM for Accessible Outcomes

Ask for:

-   Equivalent information across sensory channels.
-   Text descriptions of visual elements.
-   Non-visual representations of interaction state.
-   Compatibility with assistive technologies.

------------------------------------------------------------------------

# 12. Designing with AI as a Creative Partner

AI tools can accelerate design but may reproduce inaccessible patterns
if not guided explicitly. Designers must provide clear constraints that
prioritise inclusion, autonomy, and multimodal communication. Prompting
should emphasise outcomes rather than visual aesthetics alone. Treat AI
as a collaborator requiring direction rather than an autonomous
decision-maker.

## Prompting Methodology Principles

When writing prompts:

1.  State that accessibility is a core requirement.
2.  Specify multiple input and output modalities.
3.  Require compatibility with assistive technologies.
4.  Ask for explanations of interaction logic.
5.  Request alternatives for sensory or motor differences.
6.  Emphasise user control and predictability.
7.  Avoid assumptions about user ability.

------------------------------------------------------------------------

# 13. Integrating Accessibility into Design Practice

Accessibility should be embedded into ideation, prototyping, critique,
and evaluation. Teams should normalise inclusive thinking so
accessibility decisions occur naturally rather than as additional work.
Design artefacts such as journey maps, wireframes, and prototypes should
include accessibility annotations from the start. Continuous learning
and iteration strengthen inclusive capability over time.

------------------------------------------------------------------------

# 14. Conclusion

Inclusive interaction design improves usability, reduces friction, and
enhances user trust across all audiences. By considering variability in
perception, cognition, and movement, designers create experiences that
are more resilient and adaptable. When AI tools are guided with explicit
accessibility intent, they can amplify inclusive creativity rather than
undermine it. Accessibility is therefore both a design quality indicator
and a driver of better experiences for everyone.

Multimodal Inclusive Design Maturity Model

Purpose
This maturity model helps organisations evaluate how effectively they design experiences that work across multiple sensory modalities and interaction methods, ensuring that people with diverse abilities can participate equally and enjoyably.

It focuses on experience quality, equity of participation, and organisational capability rather than compliance.

The Five Levels of Maturity

Level 1 — Single-Mode Awareness
Experiences are primarily designed for one dominant modality, usually visual and pointer-based interaction. Accessibility is considered late or treated as a technical requirement.

Level 2 — Alternative Modality Support
Teams recognise the need for multiple modalities and provide alternatives, but these are often treated as secondary experiences.

Level 3 — Equivalent Multimodal Experiences
Multimodality is intentionally designed to provide equivalent outcomes across senses and inputs. Inclusive design is considered early.

Level 4 — Integrated Multimodal Systems
Multimodal thinking becomes systemic across platforms and teams. Experiences feel coherent regardless of modality.

Level 5 — Adaptive Inclusive Experience Ecosystem
Experiences dynamically adapt to user context, ability, and environment. Inclusion becomes embedded culturally and strategically.

Maturity Dimensions

1. Sensory Flexibility
2. Input Flexibility
3. Platform Consistency
4. Experience Parity
5. Context Awareness
6. Design Process Integration
7. Organisational Capability

Assessment Questions for Leaders

Strategy
- Do we define inclusion as experience quality or compliance?
- Is multimodality part of design vision?

Design Practice
- Do designers consider multiple senses during ideation?
- Are flows tested without visual reliance?

Research
- Do we test with diverse interaction methods?
- Do we study contextual constraints?

Systems
- Does our design system include sensory behaviour patterns?
- Are feedback states consistent across modalities?

Culture
- Do teams expect human variability?
- Is accessibility expertise distributed?

Executive Summary
Multimodal inclusive maturity reflects how deeply an organisation understands human variability and designs experiences that adapt to people rather than forcing people to adapt to systems.


# Multimodal Inclusive Design

## Knowledge Base for Designers

------------------------------------------------------------------------

# 1. Core Philosophy

Multimodal design means creating experiences that can be understood and
controlled using more than one human sense or interaction method.

From an inclusive design perspective, multimodality is not a new trend.
It began when designers needed to make experiences accessible for people
who could not rely on a single sensory channel.

If someone cannot hear, information must be available visually or
through touch.\
If someone cannot see, information must be available through sound or
touch.\
If someone cannot use their hands, interaction must be possible through
voice or alternative controls.

Multimodal design is therefore best understood as:

> Designing equivalent experiences across sensory and interaction
> differences.

The goal is not to provide identical experiences, but experiences that
are **equally usable, understandable, and enjoyable**.

Inclusive multimodal design benefits everyone because human abilities
change constantly depending on context, environment, and situation.

------------------------------------------------------------------------

# 2. Modalities: The Building Blocks

## Input Modalities (how people control systems)

At minimum, interfaces should be operable through:

1.  Pointing devices (mouse, trackpad, eye tracking)\
2.  Keyboard or switch control\
3.  Voice input\
4.  Touch or gesture

Inclusive design assumes that no single input method works for everyone.

## Output Modalities (how systems communicate)

Systems communicate through:

-   Visual information (text, graphics, motion)\
-   Audio (speech, sound cues, alerts)\
-   Tactile feedback (vibration, force, texture)\
-   Spatial or environmental feedback

The key inclusive principle:

> Important information should never exist in only one modality.

------------------------------------------------------------------------

# 3. Accessibility as Modality Translation

Inclusive multimodal design can be understood as **modality
translation**.

Examples:

  Original Modality   Equivalent Modalities
  ------------------- ----------------------------------------
  Sound               Captions, visual indicators, vibration
  Visual text         Speech output, tactile displays
  Images              Spoken description, tactile diagrams
  Touch interaction   Voice commands, keyboard input
  Audio alerts        Visual cues, haptic signals

Accessibility ensures meaning survives across senses.

------------------------------------------------------------------------

# 4. Designing for Equivalent Enjoyment

Inclusive multimodal design is not only about access. It is about
experience quality.

Two experiences can both be accessible but feel very different
emotionally.

Designers should aim for **equivalent satisfaction**, not just
equivalent functionality.

Important questions:

-   Does the experience feel responsive in every modality?
-   Does each modality communicate confidence?
-   Does each modality create trust?
-   Does each modality support flow rather than interruption?

------------------------------------------------------------------------

# 5. Platform Considerations

## Mobile

Design approaches:

-   Provide voice alternatives for complex typing
-   Use haptic confirmation for actions
-   Ensure screen reader compatibility
-   Provide clear visual hierarchy

Key question:

> Can this task be completed without looking at the screen?

## Web

Design approaches:

-   Structured semantic content
-   Clear focus states
-   Alternative text for images
-   Captions and transcripts for media

Key question:

> If visual design disappeared, would the experience still make sense?

## Television and Large Screens

Design approaches:

-   High contrast visuals
-   Large readable text
-   Voice input for search
-   Simple navigation depth

Key question:

> Can someone understand this from across the room?

## Voice Interfaces

Design approaches:

-   Confirm actions clearly
-   Provide repeat options
-   Allow interruption
-   Offer multimodal fallback

Key question:

> If the system misunderstood, how easily could the user recover?

# 6. Touch and Tactile Modality

Tactile communication can include:

-   Vibrations indicating success or error
-   Texture differences
-   Force feedback
-   Physical affordances

Design question:

> What information could be felt instead of seen or heard?

# 7. Context Awareness

Human ability changes with context.

Good multimodal systems adapt by:

-   Offering alternative modalities
-   Changing feedback intensity
-   Simplifying interaction when needed
-   Allowing user control

Important principle:

> The user should never be trapped in one modality.

------------------------------------------------------------------------

# 8. Mental Models and Expectations

Inclusive multimodal design should:

-   Use familiar patterns
-   Avoid unexpected modality changes
-   Maintain consistency across senses
-   Reinforce actions with multiple cues

Consistency increases confidence and reduces errors.

# 10. Cognitive Load and Modality Choice
